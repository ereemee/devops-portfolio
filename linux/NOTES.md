# Linux 정리 노트

> 1단계 Linux·운영체제 기초 학습 기록 (WSL2 Ubuntu 환경)

## 1. 오늘 쓴 명령 (2026-11-13)

| 명령 | 뜻 | 언제 쓰나 |
| --- | --- | --- |
| `whoami` | 현재 로그인한 사용자 이름 출력 | 권한 문제가 날 때 "누구로 실행 중인지" 확인 |
| `pwd` | 현재 위치(디렉터리) 출력 | 스크립트·명령을 어디서 실행하는지 확인 |
| `ls -la` | 숨김 파일 포함 목록 + 권한·소유자·크기 표시 | 파일이 있는지, 권한이 맞는지 확인 |
| `mkdir -p a b/c` | 폴더 만들기 (`-p`: 중간 폴더까지, 이미 있어도 오류 없음) | 프로젝트 폴더 구조 만들 때 |
| `cd <경로>` | 디렉터리 이동 | 작업 위치 바꿀 때 |
| `nano <파일>` | 터미널 텍스트 편집기 (저장 Ctrl+O, 종료 Ctrl+X) | 서버에서 설정 파일·스크립트 수정할 때 |
| `chmod +x <파일>` | 실행 권한 추가 | 스크립트를 `./파일`로 실행하기 전 |
| `df -h` | 디스크 사용량 (`-h`: GB/MB 단위) | 디스크가 꽉 차서 장애가 날 때 첫 확인 |
| `free -h` | 메모리 사용량 | 서버가 느릴 때 메모리 부족인지 확인 |
| `ps aux --sort=-%mem \| head -6` | 메모리를 많이 쓰는 프로세스 상위 5개 | 어떤 프로그램이 자원을 잡아먹는지 찾을 때 |
| `sudo apt update && sudo apt upgrade -y` | 패키지 목록 갱신 후 전체 업그레이드 | 서버 초기 세팅, 보안 패치 |
| `wsl` / `exit` | (PowerShell) Ubuntu로 들어가기 / (bash) 나오기 | Windows ↔ Linux 전환 |

### 출력 읽는 법 메모
- `df -h`: **Use%** 열이 80% 이상이면 주의
- `free -h`: **used**보다 **available**(실제로 더 쓸 수 있는 양)을 본다
- `ps aux`: **%CPU**, **%MEM**, **COMMAND**(어떤 프로그램인지) 열을 본다

## 2. 파일 권한 (rwx)

`ls -la` 출력 예:
```
-rwxr-xr-- 1 hyerim hyerim 512 Nov 13 13:00 server_check.sh
│└┬┘└┬┘└┬┘   └─소유자 └─그룹
│ │  │  └ 기타 사용자(others)
│ │  └─── 그룹(group)
│ └────── 소유자(user)
└──────── 파일 종류: - 파일, d 디렉터리, l 링크
```

| 기호 | 숫자 | 파일에서 | 디렉터리에서 |
| --- | --- | --- | --- |
| `r` | 4 | 내용 읽기 | 목록 보기(`ls`) |
| `w` | 2 | 내용 수정 | 파일 생성·삭제 |
| `x` | 1 | 실행 | 들어가기(`cd`) |
| `-` | 0 | 권한 없음 | 권한 없음 |

### 자주 쓰는 숫자 조합
| 숫자 | 기호 | 용도 |
| --- | --- | --- |
| `755` | `rwxr-xr-x` | 스크립트·디렉터리 (나는 전부, 다른 사람은 읽기·실행) |
| `644` | `rw-r--r--` | 일반 파일 (나는 읽기·쓰기, 다른 사람은 읽기) |
| `600` | `rw-------` | 비밀 파일 (SSH 키, .env 등 나만) |

```bash
chmod 755 linux/server_check.sh   # 숫자 방식
chmod u+x,go-w file               # 기호 방식 (u 소유자, g 그룹, o 기타)
```

> ⚠️ `/mnt/c` 아래 파일은 Windows 디스크라 모두 `rwxrwxrwx`로 보이고 `chmod`가 반영되지 않는다.
> 권한 실습은 WSL 홈(`~`)에서 하고, git에는 `git update-index --chmod=+x <파일>`로 실행 권한을 기록한다.

## 3. 트러블슈팅

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| PowerShell에서 `mkdir -p a b` 오류 | bash 명령을 PowerShell에서 실행 | PowerShell은 `mkdir a, b -Force`, 또는 `wsl` 입력 후 실행 |
| `ls: cannot access` | 경로 오타 또는 폴더 없음 | `pwd`로 위치 확인, 철자 확인 |
| `env: $'bash\r': No such file or directory` | 스크립트가 CRLF 줄바꿈으로 저장됨 | `sed -i 's/\r$//' 파일` 후 VS Code에서 LF로 저장 |
